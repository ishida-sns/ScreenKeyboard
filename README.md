# ScreenKeyboard

Windows用のスクリーンキーボードとタッチパッドが一体化したC# WPFアプリケーションです。

## 概要

このアプリケーションは、Windows環境でマウスやキーボードが使用できない状況でも、タッチスクリーンやその他の入力デバイスを使用してコンピュータを操作できるように設計されています。

## 機能

### スクリーンキーボード
- **英字キー**: A-Z (QWERTY配列)
- **数字キー**: 0-9
- **特殊文字**: 記号や句読点など
- **機能キー**: Space、Enter、Backspace、Tab、Esc、Ctrl、Alt、Win
- **Shiftキー**: トグル式で大文字入力が可能

### タッチパッド
- **カーソル移動**: タッチパッド領域をドラッグしてマウスカーソルを移動
- **左クリック**: 専用ボタンで左クリックを実行
- **右クリック**: 専用ボタンで右クリックを実行
- **感度調整**: スライダーでカーソル移動の感度を1x～20xまで調整可能

## ビルド方法

### 必要な環境
- .NET 6.0 SDK 以上
- Windows OS (実行環境)

### ビルド手順

```bash
# リポジトリのクローン
git clone https://github.com/ishida-sns/ScreenKeyboard.git
cd ScreenKeyboard

# ビルド
dotnet build

# 実行
dotnet run
```

### リリースビルド

```bash
dotnet publish -c Release -r win-x64 --self-contained
```

## 使い方

1. アプリケーションを起動します
2. 左側のキーボードセクションで、クリックしたいキーをクリックします
3. 右側のタッチパッドセクションで、ドラッグしてマウスカーソルを移動します
4. 左クリック・右クリックボタンで、マウスクリックを実行します
5. 感度スライダーで、タッチパッドの感度を調整できます

## 技術仕様

- **フレームワーク**: .NET 6.0 (WPF)
- **言語**: C#
- **UI**: XAML
- **Windows API**: user32.dll を使用してキーボードとマウスのイベントをシミュレート

## ライセンス

このプロジェクトはオープンソースです。

## 注意事項

- このアプリケーションはWindows専用です
- キーボードとマウスのシミュレーションには管理者権限が必要な場合があります
- セキュリティソフトウェアによってブロックされる可能性があります
